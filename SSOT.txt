# 1. Keputusan Arsitektur Final

Keputusan berikut bersifat **final dan mengikat** untuk production.

## 1.1 Production menggunakan satu Docker image

Production GolanInvite harus dibangun menjadi:

```text
1 Docker Image
```

Image tersebut berisi:

```text
Go application binary
+
embedded frontend production assets
+
migration files apabila diperlukan
+
runtime configuration yang tidak bersifat secret
```

---

## 1.2 Production hanya menjalankan satu application process

Container aplikasi production hanya menjalankan:

```text
1 Go binary
```

Tidak boleh menjalankan:

```text
Node.js server
Next.js server
npm start
next start
PM2
supervisor untuk menjalankan frontend
process manager untuk menjalankan Go + Node
```

Node.js hanya digunakan pada **build stage**.

---

## 1.3 Next.js hanya merupakan frontend/build-time framework

Next.js tetap digunakan untuk membangun frontend.

Namun pada production:

```text
Node.js tidak dijalankan.
```

Frontend harus menghasilkan artifact yang dapat disajikan sebagai static/client-side production assets oleh Go.

Konsekuensinya:

* business logic tidak boleh bergantung pada Next.js server runtime;
* authentication tidak boleh bergantung pada Node.js;
* database tidak boleh diakses Next.js;
* Server Actions tidak boleh menjadi business API utama;
* API utama tetap REST API Go;
* SSR yang mengharuskan Node.js runtime tidak boleh menjadi requirement production;
* fitur frontend harus dapat dijalankan menggunakan production assets yang disajikan Go.

Apabila suatu fitur baru secara mutlak membutuhkan Node.js production runtime, fitur tersebut **tidak boleh langsung ditambahkan**.

SSOT harus diubah terlebih dahulu.

# 2. Prinsip Runtime Utama

Perubahan data bisnis **tidak boleh memerlukan restart aplikasi**.

Operasi berikut harus dapat dilakukan secara runtime:

```text
Tambah user
Edit user
Tambah template
Update template
Publish versi template
Nonaktifkan template
Tambah undangan
Edit undangan
Publish undangan
Tambah custom domain
Update custom domain
Verifikasi domain
Aktifkan domain
Nonaktifkan domain
Ubah paket
Ubah harga
Ubah landing page
Terima order
Tolak order
Proses order
Data injection
Submit RSVP
Submit ucapan
Moderasi ucapan
Submit review
Balas review
```

Semua operasi tersebut merupakan:

```text
data/configuration changes
```

bukan:

```text
application deployment
```

Karena itu:

```text
TIDAK memerlukan:
docker build
docker restart
container restart
Go restart
Next.js rebuild
```

Restart/redeploy hanya diperlukan apabila terjadi perubahan:

```text
source code Go
source code frontend
dependency aplikasi
database schema tertentu
embedded static application assets
system-level configuration tertentu
```

# 22. Hostname Resolver

Backend wajib memiliki hostname resolver.

Alur:

```text
HTTP request
→ read Host
→ remove port
→ lowercase
→ remove trailing dot
→ validate hostname
→ determine host type
→ database lookup
→ attach HostContext
```

Contoh:

```go
type HostContext struct {
    Type         HostType
    Hostname     string
    InvitationID *uuid.UUID
```


Hostname tidak dikenal harus ditolak.

# 26. Dynamic Domain — Tidak Memerlukan Restart

Penambahan domain harus bekerja seperti:

```text
Admin
→ Create Domain
→ PostgreSQL
→ status pending
→ DNS verification
→ TLS provisioning
→ HTTPS verification
→ status active
```

Tidak boleh ada langkah:

```text
restart Go
restart container
rebuild Docker
rebuild frontend
```

Go membaca domain dari database saat runtime.

Jika hostname resolution menggunakan cache, sistem harus:

* melakukan invalidation setelah domain berubah; atau
* menggunakan TTL terbatas.

Cache tidak boleh membuat domain baru membutuhkan restart.

# 28. SSL / HTTPS

Semua domain aktif wajib menggunakan HTTPS.

Reverse proxy/certificate layer harus mendukung:

* multiple hostnames;
* dynamic domain;
* automatic certificate issuance;
* automatic certificate renewal;
* hot reload;
* Host preservation.

**Penambahan SSL/domain tidak boleh membutuhkan restart aplikasi Go.**

Proxy diperbolehkan melakukan dynamic configuration/hot reload tanpa menghentikan application container.

Private key TLS tidak disimpan pada database aplikasi.

Database hanya menyimpan status SSL.

# 42. Validasi Periode

Public invitation tersedia apabila:

```text
domain.status = active
AND invitation.status = active
AND current_time >= start_at
AND current_time <= end_at
```

Jika belum dimulai:

```text
Undangan belum tersedia
```

Jika expired:

```text
Masa aktif undangan telah berakhir
```

Jika disabled:

```text
Undangan tidak tersedia
```

Jika hostname tidak dikenal:

```text
Domain undangan tidak ditemukan
```

# 100. Performance Principles

Dapat menggunakan caching untuk:

* landing;
* package;
* template metadata;
* hostname resolution;
* public invitation data.

Runtime configuration tidak boleh bergantung pada restart untuk refresh cache.

# 101. Domain Cache

Jika hostname resolver menggunakan cache:

```text

```

setelah admin mengubah domain:

```text

→ commit
→ invalidate hostname cache
```

Tidak boleh menggunakan cache permanen sampai restart.

# 102. Template Cache
